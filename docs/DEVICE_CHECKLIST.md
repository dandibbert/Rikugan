## 1. 安装与环境
- [ ] 重签后可安装并启动；诊断页显示的 commit 与发布一致
- [ ] 诊断：App Group “可用”（需要签名时带上 `group.com.dandibbert.Rikugan`），否则记录“不可用”
- [ ] 诊断：分享扩展“已嵌入”；从 Safari / 其他 App 分享网址 → 在 Rikugan 中打开
- [ ] 诊断 → 导出诊断信息：JSON 中只有域名，无路径 / 查询参数、Cookie、密码、脚本源码

## 2. 标签页生命周期（真实内存压力）
- [ ] 打开 30+ 个真实网站（新闻、视频、社交站点混合），分到 3 个组
- [ ] 诊断中“后台存活”不超过设置的上限；“存活 WKWebView”数量合理
- [ ] 切回很久未访问的标签页：页面恢复到原网址、可以后退、滚动位置大致恢复
- [ ] 在后台打开大量 App（相机、游戏）后回到 Rikugan：标签页与组都在，当前标签页恢复
- [ ] 长时间播放视频的标签页被系统杀进程后（诊断“进程终止”计数增加）切回时重新加载，不白屏
- [ ] 系统内存警告后（可用 Xcode Debug → Simulate Memory Warning，或打开大量重页面）后台标签页被挂起，前台不受影响
- [ ] 强制退出 App 后重启：标签页顺序、组、当前组、当前标签页恢复

## 3. 标签页组
- [ ] 创建 / 重命名 / 调整组顺序 / 删除组（两种方式：关闭其标签页、移到“标签页”）
- [ ] 拖动标签页调整顺序；把标签页移到另一个组
- [ ] 无痕标签页不出现在任何组中，不会被导出、不会被恢复

## 4. 扩展后台运行时
- [ ] 安装 Dark Reader：切换开关 / 调整亮度后页面立即变化；退到后台 5 分钟再回来仍可用
- [ ] 安装 uBlock Origin Lite：广告网站上广告被拦截；Popup 能打开并显示当前网站
- [ ] 扩展 Popup 在 App 刚启动（后台尚未就绪）时打开：不报错，数据正确
- [ ] 设置 → 开发者：“扩展后台空闲挂起”设为 30 秒，等待后诊断显示 suspended；再次使用扩展时恢复（ready）
- [ ] 诊断中无“后台运行时启动失败”错误

## 5. 用户脚本
- [ ] 安装一个依赖 `unsafeWindow` 的真实脚本（例如修改页面函数的脚本）并确认生效
- [ ] 安装一个 `@grant GM_xmlhttpRequest` 的脚本，跨域请求成功，`@connect` 限制生效
- [ ] 单页应用（例如 GitHub、YouTube）中 pushState 跳转后脚本行为符合脚本自身设计

## 6. 字体
- [ ] 通过描述文件安装一个系统字体，在“网页字体”中选择后网页正文使用该字体
- [ ] 导入 .ttf / .otf / .ttc，分别设置为正文 / 标题 / 等宽
- [ ] 打开 GitHub（Octicons）、使用 Font Awesome / Material Icons 的网站：图标正常，不变成方块或字母
- [ ] 为某个网站设置不同字体、为某个网站禁用字体，确认互不影响
- [ ] Emoji 仍为彩色

## 7. 内容拦截 / DNR
- [ ] 内置规则 + 订阅在真实网站上生效；白名单网站不拦截
- [ ] 诊断中 DNR redirect / modifyHeaders 能力与 CI 报告一致（同一 iOS 版本）

## 8. 导入导出
