- [ ] 诊断 → 环境：App Group 是否“可用”，分享扩展是否“已嵌入”（记录实际状态）

## 4. 扩展：从商店安装（本次修复）
- [ ] 设置 → 扩展 → “打开 Chrome 应用商店”：设置页自动关闭，商店在**新标签页**打开
- [ ] 在商店里点进 Dark Reader 详情页：页面顶部出现“安装到 Rikugan”栏（商店自己的按钮在 iPhone 上本来就不可用，Chrome 提示仅限桌面，Edge 按钮为灰色，这属于预期）
- [ ] 点“添加” → 显示权限确认 → 安装成功，扩展出现在扩展列表
- [ ] 同样从 Edge 加载项安装一个扩展（例如 Edge 上的 Dark Reader）
- [ ] 设置 → 扩展 → “通过商店链接或扩展 ID 安装”：粘贴 uBlock Origin Lite 的商店链接可以安装；输入乱码时提示无法识别
- [ ] 已安装扩展的详情页上，顶部栏显示“已安装到 Rikugan / 重新安装”

## 5. 扩展：功能与后台
- [ ] Dark Reader：开关、调亮度后页面立即变化；Popup 能打开、能按网站切换
- [ ] uBlock Origin Lite：广告多的网站上广告被拦截；Popup 显示当前网站
- [ ] App 刚启动时立刻打开扩展 Popup：不报错，数据正确
- [ ] 开发者 → 扩展后台运行时：对 Dark Reader 点“挂起”，然后在网页上使用它：自动唤醒，“唤醒次数”+1，状态回到 ready
- [ ] 同一页面点“停止并重建”，扩展仍可用
- [ ] 长时间使用（1 小时以上）后查看每个扩展的“卡住恢复”次数；大于 0 时打开“状态时间线”截图，或直接导出诊断
- [ ] 沉浸式翻译：Popup 能显示；页面上的翻译按钮出现（实际翻译需要它的服务，记录能否使用）
