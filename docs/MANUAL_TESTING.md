# 人工测试与诊断导出指南（PlayCover / 真机）

CI 只证明模拟器上的结果。本页说明如何在 PlayCover 或 iPhone / iPad 上做人工测试、记录结果、导出诊断文件。人工结果永远标注为“人工”，不会被当成 CI 结果。

## 1. 安装与确认版本

1. 从 Release 下载：
   - `Rikugan-<版本>-unsigned.ipa`
   - `SHA256SUMS.txt`
   - `build-metadata.json`
2. 校验：`shasum -a 256 -c SHA256SUMS.txt`。
3. 安装：
   - PlayCover：导入 IPA，由 PlayCover 自行签名；
   - 真机：用 AltStore / Sideloadly / TrollStore / 开发者证书重签后安装。
4. 打开 **设置**，看最底部一行：`Rikugan <版本> (<构建号>) · commit <前 12 位>`。它必须与 `build-metadata.json` 中的 `commitShort` 一致。完整信息在 设置 → 开发者 → 打开诊断 → 构建。

## 2. PlayCover 冒烟清单（按顺序执行）

每一步都在 设置 → 开发者 → **人工测试清单** 中记录 通过 / 失败 / 不适用，失败时写备注。

1. **启动与版本**：App 能启动，设置底部的 commit 与 Release 一致。
2. **基本浏览**：打开 https://example.com，搜索一个关键词，前进 / 后退 / 刷新。
3. **标签页**：
   - 新建 8 个标签页、建 1 个组，逐个切回，确认已挂起的标签页恢复且位置不丢；
   - 强制退出后重开，会话恢复。
4. **自检**：设置 → 自检，依次运行 `core`、`security`、`pageworld`、`dnr`，记录 n/m。这些是 PlayCover 上的 App 内结果，要写明来源。
5. **用户脚本**：
   - 安装一个 `@grant none` 脚本和一个使用 `GM_setValue` / `GM_xmlhttpRequest` 的脚本，在目标网站确认生效；
   - 查看脚本详情中的运行环境标注。
6. **扩展**：
   - 安装 Dark Reader（Chrome 应用商店 CRX 或 GitHub ZIP），打开 Popup 切换站点；
   - 安装 uBlock Origin Lite，访问广告较多的网站。
7. **后台唤醒**：设置 → 开发者 → 扩展后台运行时：
   - 对 Dark Reader 点“挂起”，然后在页面上使用 Dark Reader；
   - 确认自动唤醒，唤醒次数加 1、状态回到 ready；
   - 再试“停止并重建”。
8. **下载与媒体**：
   - 下载一个 PDF / ZIP 并在下载管理中打开；
   - 在视频页打开媒体面板，确认检测到媒体。
9. **导入导出**：导出归档，在另一个身份中导入，检查书签 / 脚本 / 设置。
10. **诊断导出**：
    - 诊断 → 导出诊断报告，保存到“文件”；
    - 打开 JSON，确认没有完整网址路径、Cookie、密码或脚本存储值。
11. **系统集成**：人工测试清单中标记“仅真机”的项目，在 PlayCover 上设为“不适用”。

## 3. 真机

先完成上面的清单，再做“系统集成（仅真机）”一节：

- 分享扩展、App Group、“文件”选择器边界情况；
- 照片、相机、画中画、AirPlay；
- 外部 URL scheme、系统 / 描述文件字体；
- WebContent 进程终止 / 内存压力。

详细步骤见 [DEVICE_CHECKLIST.md](DEVICE_CHECKLIST.md)。

**后台运行时证据**：长时间使用后，打开 开发者 → 扩展后台运行时，记录每个扩展的唤醒次数、冷启动次数、卡住恢复次数。若卡住恢复次数大于 0，在“状态时间线”中截图，或直接导出诊断文件（其中包含最近的状态迁移）。

## 4. 诊断导出包含 / 不包含什么

导出文件为单个 JSON：`Rikugan-diagnostics-<时间戳>.json`，格式 `rikugan-diagnostics/2`。

**包含**：

- 构建：版本、commit、构建时间；
- 系统版本与设备型号、生成时间；
- 标签页生命周期计数；
- 扩展后台运行时：每个扩展的状态、是否驻留、上次唤醒时间、唤醒 / 冷启动 / 卡住恢复 / 失败重启次数、活动端口数、最近的状态迁移；
- 总数：已安装扩展、运行中后台、驻留后台、浏览器标签页 WebView、Rikugan 拥有的 WKWebView 总数（按用途分）；
- 扩展与用户脚本的名称、版本、权限 / 授权、运行环境；
- 兼容性矩阵版本（内置矩阵 JSON 的 sha256）；
- 最近的运行时错误与安全拒绝记录（网址只保留域名）；
- 功能开关（不含 API Key、服务器地址、主页或搜索模板）；
- DNR 跳过规则摘要；
- 人工测试状态与备注（明确标注 `manual … not CI results`）。

**不包含**：

- 密码、Cookie、钥匙串内容；
- 网页内容与表单内容；
- 完整浏览网址（只保留域名，URL 中的 `user:password@` 也会去掉）；
- 用户脚本源码与 GM 存储值；
- 扩展存储；
- 归档内容。

**内存**：iOS 没有公开 API 提供每个 WebContent 进程的内存用量，所以导出中只有 WebView 数量，没有内存数字。

请把诊断文件和人工测试清单的结果一起附在反馈中，并写明：

- 运行环境：PlayCover 版本 + macOS + Mac 型号，或者设备型号 + iOS 版本；
- 安装方式。
